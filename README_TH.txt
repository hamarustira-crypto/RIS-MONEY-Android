RIS MONEY - Android starter project

สิ่งที่มีในเวอร์ชันนี้
- แอป Android แบบ native ด้วย Kotlin + Jetpack Compose
- บันทึกรายรับและรายจ่าย
- คำนวณยอดคงเหลืออัตโนมัติ
- เก็บข้อมูลไว้ในเครื่องด้วย SharedPreferences
- ลบรายการ และสลับธีมมืด/สว่าง

วิธีสร้าง APK
1. ติดตั้ง Android Studio บนคอมพิวเตอร์
2. แตกไฟล์ ZIP
3. เปิดโฟลเดอร์ RIS_MONEY_Android ด้วย Android Studio
4. รอ Gradle Sync ให้เสร็จ
5. เลือก Build > Build Bundle(s) / APK(s) > Build APK(s)
6. ไฟล์ APK จะอยู่ที่ app/build/outputs/apk/debug/app-debug.apk

ข้อจำกัดเวอร์ชันเริ่มต้น
- ยังไม่มีระบบสมัครสมาชิก/ซิงก์ข้ามเครื่อง เพราะต้องมี backend และระบบยืนยันตัวตน
- ยังไม่เชื่อมธนาคารหรือ PromptPay อัตโนมัติ การอ่านธุรกรรมต้องใช้ API/ผู้ให้บริการที่ได้รับอนุญาต
- ข้อมูลเก็บในเครื่องนี้เท่านั้น ควรสำรองข้อมูลก่อนลบแอป

แนะนำให้ทดสอบด้วยข้อมูลตัวอย่างก่อนใช้บันทึกเงินจริง
